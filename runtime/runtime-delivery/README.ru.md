# runtime-delivery

Библиотека надёжной доставки через PostgreSQL inbox/outbox: дедупликация входа, транзакция бизнес-обработки, хранение
исходящих сообщений и отправка с повторами.

## Пакеты

Классы разделены по назначению внутри `ru.petrovov.iib_camel.runtime.delivery`:

| Пакет     | Ответственность                                                               |
|-----------|-------------------------------------------------------------------------------|
| `config`  | Автоконфигурация Spring, параметры доставки и подключение планировщика        |
| `handler` | Контракт `MessageHandler` для бизнес-обработчиков модулей                     |
| `inbox`   | Приём сообщения, дедупликация, транзакция обработки и результат приёма        |
| `outbox`  | Статусы исходящих сообщений, хранилище, захват записей и отправка с повторами |
| `jdbc`    | Общие средства хранения заголовков и проверки PostgreSQL                      |

Тесты следуют той же структуре. `OutboxStore` имеет публичный тип для подключения конфигурационного bean, но его
операции остаются package-private; модули используют `InboxService` и `MessageHandler`, а Spring регистрирует
отправитель `OutboxDispatcher` и планировщик.

Границы транзакций, гарантии доставки и эксплуатационные ограничения описаны
в [контракте доставки](../docs/delivery.ru.md). Место библиотеки в приложении показано
в [архитектуре runtime](../README.ru.md#архитектура).
