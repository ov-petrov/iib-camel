# Пример подключаемого модуля

Нейтральный модуль `example` показывает передачу исходных байтов через PostgreSQL outbox. Бизнес-преобразования в нём нет. Включается свойством `IIB_MODULE_EXAMPLE_ENABLED=true`; после добавления собственного модуля этот пример можно оставить выключенным.

Вход задаётся `IIB_MODULE_EXAMPLE_INPUT_URI`: `artemis:queue:EXAMPLE.IN`, `ibmmq:queue:EXAMPLE.IN` или `kafka:example-input?groupId=example-runtime`. Для локального вызова допустим `direct:example-input`. Требуется включить соответствующий транспорт и указать адрес и авторизацию. Источник дедупликации задаётся `IIB_MODULE_EXAMPLE_SOURCE_ID`.

Принимаются `BytesMessage` и UTF-8 текст. Для дедупликации используется `applicationEventId`, затем Kafka topic/partition/offset либо `JMSMessageID`. Вызов без стабильного идентификатора отклоняется. Пример сохраняет только тело сообщения; перенос прикладных заголовков реализуйте явно в своём модуле, выбрав нужные `MessageHeader` и формат кодирования. MQRFH2 и произвольные деревья IIB автоматически не переносятся.

Вход и один выход записываются атомарно. При ошибке БД исключение возвращается потребителю, чтобы он повторил доставку. Kafka offset подтверждается синхронно после завершения транзакции; не добавляйте перед этим асинхронные этапы. Один вход с тем же идентификатором и другим телом считается конфликтом. Для постоянных ошибок задайте политику повторов и карантин на брокере; универсальная политика DLQ не скрывает ошибки внутри runtime.

Выход задают `IIB_MODULE_EXAMPLE_OUTPUT_TRANSPORT` (`artemis`, `ibmmq`, `kafka`) и `IIB_MODULE_EXAMPLE_OUTPUT_DESTINATION`. Отправитель запускается при `IIB_DELIVERY_PUBLISHER_ENABLED=true`. Получатель должен дедуплицировать стабильный `applicationEventId`: доставка как минимум один раз, а `PROCESSED` означает принятие брокером.

Для проверки запустите PostgreSQL и нужные брокеры по [инструкции runtime](../../README.ru.md). Все имена и данные примера синтетические. Документацию реальных модулей с конфиденциальными контрактами храните в закрытом проекте, а не в публичном репозитории.
