# xsd-tool

Инструмент для генерации Java DTO и примеров XML из XSD 1.0. Он собирается на JDK 21 и запускается как отдельный исполняемый JAR.

При запуске `xsd-tool.jar` без аргументов инструмент читает XSD из каталога `input` рядом с JAR и складывает DTO
и примеры XML в соседний каталог `output`.

- Eclipse XJC компилирует схему в Java-классы с аннотациями `jakarta.xml.bind`. Сгенерированные исходники можно вручную скопировать в нужный Java-модуль. [Eclipse XJC](https://eclipse-ee4j.github.io/jaxb-ri/4.0.5/docs/release-documentation.html)
- Apache XMLBeans подбирает синтетические значения и строит примеры для глобальных элементов. Инструмент сохраняет XML после валидации по исходной XSD. [Apache XMLBeans xsd2inst](https://xmlbeans.apache.org/guide/Tools.html)

Оба результата можно получить за один запуск или сгенерировать по отдельности. Инструмент разрешает локальные `include`, `import` и `redefine` в пределах каталога входных схем. Для `xs:choice` он пробует первую ветку, а значения примера могут различаться между запусками. Если валидный XML получить не удаётся, инструмент выводит диагностику.
