# Проверки совместимости конвертера

`legacy-runtime` сохраняет прежний исполнитель сгенерированных маршрутов и регрессионные тесты конвертера. Это тестовое окружение на Java 25. Оно не является новым самостоятельным приложением интеграций.

Проверка из корня репозитория:

```sh
mvn -B -pl converter,compatibility-tests/legacy-runtime -am verify
```

Корпус синтетических IIB-файлов расположен в `converter/src/test/resources/corpus`. Проверки заново генерируют и исполняют артефакты; внешние брокеры включаются отдельно через переменные окружения соответствующих тестов.

Самостоятельный runtime на Java 21 с PostgreSQL, IBM MQ, Artemis и Kafka находится в [runtime](../runtime/README.ru.md). Его модули подключаются вручную и не зависят от конвертера или этого тестового окружения.
